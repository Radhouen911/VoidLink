\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

VoidLink is a secure messaging system built on a zero-trust architecture, where the server cannot read messages or access users' private keys. This project demonstrates that it is possible to build a communication platform that mathematically guarantees the confidentiality of exchanges, without relying on trust in the service operator.

The system implements two-layer authentication: a traditional layer for account management (username/password) and a cryptographic layer using Ed25519 signatures for sensitive operations. Messages are end-to-end encrypted using NaCl (Networking and Cryptography Library) with Curve25519 keys derived from Ed25519 signing keys.

The architecture is based on a strict separation between the frontend (trusted zone) and the backend (untrusted zone). All cryptographic operations are performed client-side in the browser, and the server only handles opaque encrypted data. This approach ensures that even if the server is compromised, messages remain protected.

The project was developed with a modern technology stack: React with TypeScript for the frontend, Node.js with Express for the backend, PostgreSQL for data persistence, and WebSocket for real-time communication. The complete implementation includes contact management, real-time messaging, presence management, and a queue system for offline message delivery.

Functional tests demonstrate that the system meets security and performance requirements. The identified limitations mainly concern the absence of group messaging and multi-device synchronization, which are deliberate design choices to maintain system simplicity and security.

\textbf{Keywords:} Secure messaging, Zero-trust, End-to-end encryption, Ed25519, Curve25519, NaCl, WebSocket, Client-server architecture
