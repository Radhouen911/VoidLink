🚀 VoidLink Demo - Setup Required

⚠️ Demo Not Yet Built
The VoidLink demo application needs to be built before it can be deployed to GitHub Pages.

To Deploy the Demo:

1. Install Node.js and npm

Download and install Node.js from nodejs.org

2. Build the demo version

cd webapp/Client
npm install
npm run build:demo

3. Copy built files to gh-pages branch

git checkout gh-pages
cp -r webapp/Client/dist/* .
git add .
git commit -m "Deploy VoidLink demo"
git push origin gh-pages

About VoidLink

VoidLink is a secure messaging application with end-to-end encryption, real-time chat, and advanced security features.

Demo Features:

  • Mock authentication system
  • Simulated real-time messaging
  • Demo encryption (for demonstration purposes)
  • Offline functionality

Once built and deployed, you'll be able to test the full VoidLink demo experience!
